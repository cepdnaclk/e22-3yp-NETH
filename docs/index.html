About NETH

Bridging Camera Traps and Real-Time Ecological Context

Wildlife conservation depends on continuous, accurate observation of animal activities in natural habitats. Standard camera traps can photograph wildlife, but manual data collection in remote wilderness areas is labor-intensive and hazardous. Furthermore, traditional cameras lack synchronized environmental measurements and device health telemetry.

NETH solves this by creating an autonomous, intelligent monitoring node that couples PIR motion detection with high-speed camera acquisition, ambient temperature, relative humidity, and battery health telemetry.

Automated capture with zero disturbance to natural wildlife corridors.
Precise correlation between animal sightings and micro-climate fluctuations.
Remote device health reporting preventing unrecorded downtime.
Capabilities

Key System Features

Intelligent Image Capture

Fast hardware wake-up triggers high-resolution image recording upon animal motion detection while suppressing false foliage triggers.

Synchronized Metadata

Every captured frame is matched with millisecond timestamps, ambient temperature, relative humidity, battery level, and node ID.

Low-Power Endurance

Optimized deep-sleep current budgeting combined with solar charging ensures continuous, unattended operation across changing seasons.

Local Resilient Storage

Industrial FAT32 file system journaling protects images and telemetry logs even during sudden voltage dips or weather disruptions.

Edge AI Classification

Planned TinyML inference pipeline to filter empty frames and categorize wildlife species directly on the edge node.

Long-Range LoRa Hub

Sub-GHz LoRa RF telemetry transmits detection digests and node health heartbeats across multi-kilometer wilderness expanses.

System Blueprint

Solution Architecture

A layered cyber-physical architecture engineered for ultra-low power consumption, deterministic sensing, and long-range telemetry.

Core Operational Workflow

When an animal enters the node's surveillance zone, a low-latency hardware interrupt triggers the telemetry sequence:

1

Motion Detection & Wake-Up

PIR sensor detects displacement in infrared radiation, instantly generating a hardware interrupt to wake the MCU from deep sleep.

2

Rapid Image Capture

The vision subsystem activates the CMOS camera bus and acquires JPEG-compressed framebuffers in sub-second time.

3

Environmental & Battery Sensing

Temperature and humidity are sampled via digital bus while an ADC circuit measures real-time battery cell voltage.

4

Data Bundling & Local Storage

Sensor readings, timestamp, and device identifier are encoded and committed alongside the image to the local SD storage.

5

LoRa Telemetry & Re-Sleep

A compact telemetry payload is transmitted via LoRa to the base station, and the node returns to micro-amp sleep mode.

Architectural Layers

1. Perception Layer (Sensors)

Dual-element PIR motion detector, CMOS image sensor, calibrated ambient temperature & relative humidity sensor, and battery voltage divider.

2. Embedded & Edge Layer

Low-power microcontroller unit, FreeRTOS event management, DMA-assisted camera pipeline, and optimized TinyML classification runtime.

3. Telemetry & Transport Layer

Sub-GHz LoRa modulation (SX127x/SX126x) operating in regional ISM band with error checking and heartbeat pinging.

4. Application & Gateway Layer

Base-station gateway receiving node packets, cloud ingestion pipeline, and ecological telemetry dashboard for conservation scientists.

Firmware State Transition

Event-driven state machine ensuring optimal sleep duty cycles:

[STATE 0: DEEP SLEEP] - Disable high-draw peripheral power rails - Configure external PIR GPIO interrupt & RTC timer - Current consumption: < 50 µA [STATE 1: WAKE & VALIDATE] - Woken by: PIR Interrupt or RTC Periodic Ping - Check battery voltage & threshold integrity [STATE 2: SENSE & CAPTURE] - Power up CMOS sensor rail - Trigger camera capture & compress JPEG - Read temperature & relative humidity via digital bus - Sample battery ADC voltage divider [STATE 3: COMMIT TO DISK] - Mount SD card & write /images/NODE01_TIMESTAMP.jpg - Append telemetry record to telemetry_log.csv - Power down camera rail [STATE 4: TELEMETRY DISPATCH] - Construct compact binary LoRa packet - Transmit beacon to central receiver - Re-arm PIR interrupt & transition back to [STATE 0]

Telemetry Packet Schema

Standardized data format logged to disk and summarized over LoRa:

{ "node_id": "NETH-01-FOREST", "timestamp_utc": "2026-10-18T17:45:00Z", "trigger": "PIR_MOTION", "environment": { "temperature_c": 24.8, "humidity_pct": 78.4 }, "power": { "battery_mv": 3950, "battery_pct": 87, "solar_mv": 5120 }, "image": { "filename": "IMG_20261018_174500.JPG", "resolution": "UXGA" }, "edge_ai": { "classified": true, "label": "wildlife", "confidence": 0.91 } }

Deployment

How to Use NETH

Guidelines for setting up, mounting, and operating a NETH node in wildlife observation corridors.

1

Preparation

Insert a formatted FAT32 MicroSD card. Ensure rechargeable lithium cells are charged and solar panel surfaces are clear.

2

Mounting

Attach the weatherproof node enclosure to a tree or stake 0.5–1.5m above ground level angled toward active wildlife tracks.

3

Diagnostic Check

Power on the node. The diagnostic indicator flashes green to confirm camera, sensors, and SD card are healthy before deep sleep.

4

Data Retrieval

Retrieve logged high-res images from the SD card periodically, or monitor continuous detection digests over the LoRa receiver.

Field Configuration Template (neth_config.ini)

Placed on the SD card root to easily adjust operational parameters without reflashing firmware:

[node_settings] node_id = NETH-NODE-01 capture_resolution = UXGA ; Options: QVGA, VGA, SVGA, UXGA burst_count = 3 ; Frames to capture per trigger pir_cooldown_seconds = 10 ; Prevent redundant re-triggering deep_sleep_enabled = true ; Maximize battery runtime lora_frequency_mhz = 868.1 ; ISM band frequency heartbeat_interval_hours = 6 ; Periodic telemetry ping interval
